# デプロイ手順（Render + Supabase）

本番は **Render（Web Service, Docker ランタイム）+ Supabase（Postgres / Storage）+ Sentry** で運用する
（[開発前検討事項.md](./開発前検討事項.md) 2026-04-29 の決定）。
このリポジトリには、そのまま使える `Dockerfile` / `render.yaml` / `docker/entrypoint.sh` が含まれている。

## 0. 全体像

```
GitHub main ──(push)──> Render Web Service（Docker）──> Supabase Postgres
                              │                      └─> Supabase Storage（画像, S3 互換）
                              ├─> Sentry（エラー通知）
                              └─> SMTP（パスワード再設定メール）
```

- **ビルド**: `Dockerfile` が Tailwind / Alpine / htmx をビルドし、`collectstatic` まで済ませる
- **起動**: `docker/entrypoint.sh` が `migrate` を実行してから gunicorn を起動する
- **死活監視**: `GET /healthz/`（DB 到達まで確認。異常時は 503）

## 1. Supabase

1. プロジェクトを作成（リージョン: Northeast Asia (Tokyo)）
2. **Database** — Project Settings > Database の接続文字列を控える。
   Render から接続するときは **Session pooler** の URI（`postgresql://postgres.<ref>:<pw>@aws-0-ap-northeast-1.pooler.supabase.com:5432/postgres`）を `DATABASE_URL` に使う
3. **Storage** — バケット `bonsai-media` を作成（**非公開**。画像 URL は django-storages が署名付きで発行する）
4. **S3 アクセスキー** — Storage > Settings > S3 Access Keys で発行し、以下を控える
   - `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY`
   - `AWS_S3_ENDPOINT_URL` = `https://<ref>.supabase.co/storage/v1/s3`
   - `AWS_S3_REGION_NAME` = `ap-northeast-1`
5. **バックアップ** — 公開運用なら Pro プランにして日次バックアップを有効化する
   （Free はバックアップ無し・1 週間アクセスが無いとプロジェクトが停止する）

## 2. 外部サービス

| サービス | 用途 | 控える値 |
|---|---|---|
| Sentry | エラー通知（初日から） | `SENTRY_DSN` |
| SMTP（Resend / SendGrid など） | パスワード再設定・メール確認 | `EMAIL_HOST` `EMAIL_HOST_USER` `EMAIL_HOST_PASSWORD` `DEFAULT_FROM_EMAIL` |
| Google Cloud（任意） | Google ログイン | `GOOGLE_OAUTH_CLIENT_ID` `GOOGLE_OAUTH_CLIENT_SECRET`。承認済みリダイレクト URI に `https://<ドメイン>/accounts/google/login/callback/` を登録 |

## 3. Render

1. ダッシュボードで **New > Blueprint** を選び、このリポジトリを指定する（`render.yaml` が読まれる）
2. `sync: false` になっている環境変数を入力する（§1・§2 で控えた値）
   - `DJANGO_ALLOWED_HOSTS` = `bonsai-management.onrender.com`（独自ドメインがあればカンマ区切りで追加）
   - `CSRF_TRUSTED_ORIGINS` = `https://bonsai-management.onrender.com`（同上。**スキーム付き**）
3. デプロイが完了したら `https://<サービス名>.onrender.com/healthz/` が `ok` を返すことを確認する

### 初回だけ行う作業（Render Shell または `render ssh`）

```bash
python manage.py createsuperuser
python manage.py loaddata bonsai_species_seed monthly_advices_seed
```

- `/admin/` に入り、Google ログインを使う場合は **Sites** のドメインを本番ドメインに直し、
  **Social applications** に Google を登録する
- `/admin/` から肥料の共通マスタ・お役立ち記事を投入する

## 4. 独自ドメイン（任意）

1. Render の Settings > Custom Domains でドメインを追加し、表示された CNAME を DNS に登録する（証明書は自動）
2. `DJANGO_ALLOWED_HOSTS` と `CSRF_TRUSTED_ORIGINS` に独自ドメインを追加して再デプロイ
3. Google OAuth のリダイレクト URI にも追加

## 5. 運用

| 項目 | やること |
|---|---|
| リリース | `main` へのマージで自動デプロイ。PR 必須・CI 緑をブランチ保護で強制する |
| マイグレーション | 起動時に自動適用（単一インスタンス前提）。複数インスタンスにしたら Render の Pre-Deploy Command に移す |
| 監視 | Sentry を Slack 連携。Render の Health Check が `/healthz/` を見ている |
| バックアップ | Supabase の日次バックアップ。加えて月 1 回 `pg_dump` を手元（NAS 等）へ退避すると安心 |
| ログ | gunicorn と Django のログは標準出力 → Render Logs。`DJANGO_LOG_LEVEL` で調整 |
| スケール | `WEB_CONCURRENCY`（ワーカー数）と Render のプラン。画像が増えたら Cloudflare R2 + CDN への移行を検討（技術要件書 §画像） |

## 6. 自分用（少人数）で運用する場合の緩和

- Render `free` + Supabase Free で **0 円**で動く。ただし
  - Render Free は 15 分アクセスが無いとスリープし、次のアクセスで 30〜60 秒待つ
  - Supabase Free は 1 週間アクセスが無いとプロジェクトが停止する（ダッシュボードから再開）
- `render.yaml` の `plan: starter` を `free` に変えるだけで切り替わる

## 7. ローカルで本番イメージを試す

```bash
docker build -t bonsai-management .
docker run --rm -p 8000:8000 \
  -e DJANGO_SETTINGS_MODULE=config.settings.prod \
  -e DJANGO_SECRET_KEY=local-test -e DJANGO_DEBUG=False \
  -e DJANGO_ALLOWED_HOSTS=localhost -e CSRF_TRUSTED_ORIGINS=http://localhost:8000 \
  -e DATABASE_URL=postgres://bonsai:bonsai@host.docker.internal:5432/bonsai \
  -e USE_S3_STORAGE=False \
  bonsai-management
```

`SECURE_SSL_REDIRECT` が有効なため、ローカルでは `/healthz/` 以外は https へリダイレクトされる。
画面まで確認したい場合は `-e SECURE_SSL_REDIRECT=False` 相当の設定は用意していないので、
`config.settings.dev` で `runserver` を使うこと。

## 8. 環境変数一覧

| 変数 | 必須 | 説明 |
|---|---|---|
| `DJANGO_SETTINGS_MODULE` | ✔ | `config.settings.prod` |
| `DJANGO_SECRET_KEY` | ✔ | Render が自動生成（`generateValue`） |
| `DJANGO_DEBUG` | ✔ | `False` |
| `DJANGO_ALLOWED_HOSTS` | ✔ | カンマ区切りのホスト名 |
| `CSRF_TRUSTED_ORIGINS` | ✔ | カンマ区切り・スキーム付き |
| `DATABASE_URL` | ✔ | Supabase Postgres |
| `USE_S3_STORAGE` / `AWS_*` | ✔ | Supabase Storage（S3 互換） |
| `SENTRY_DSN` | 推奨 | 未設定なら Sentry 無効 |
| `EMAIL_*` | 推奨 | 未設定だとパスワード再設定メールが送れない |
| `GOOGLE_OAUTH_*` | 任意 | Google ログイン |
| `DJANGO_ENV` / `DJANGO_LOG_LEVEL` / `WEB_CONCURRENCY` | 任意 | 既定: production / INFO / 2 |
